Tirage d'échantillon

Interface du module Python echantillon. Le calcul se fait dans votre navigateur : aucune donnée n'est envoyée sur un serveur.

Téléchargement de Python…
Le chargement prend du temps : le premier lancement télécharge environ 25 Mo (Python et pandas), ce qui peut durer plusieurs minutes avec une connexion lente. Les fois suivantes, le navigateur réutilise ces fichiers et c'est beaucoup plus rapide.
